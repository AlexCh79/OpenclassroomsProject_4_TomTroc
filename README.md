## Librairie partagée TomTroc

## Pour utiliser ce projet :
1) Cloner le site depuis le repository GitHub (bouton "Code")
2) L'installer dans un dossier exécuté par un serveur local (type MAMP, XAMP, etc.)
3) Créer une base de données vide appelée tomtroc
4) Importer le fichier tomtroc.sql dans la base de données
5) Commencer à naviguer

## Lancer le projet :
Si nécessaire, configurez les accès à la base de données dans le fichier de configuration (selon votre installation).
Une fois la base importée et le serveur lancé, vous pouvez accéder au site via votre navigateur.
